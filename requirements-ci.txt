# Derived from the ACTUAL import chains of those tests, so CI does not pay
# for the heavy runtime stack they never import (torch / sentence-transformers
# are GBs of download). Chain analysis:
#
#   P0-1  import langgraph.checkpoint.sqlite.aio
#         -> langgraph-checkpoint-sqlite (langgraph-checkpoint transitive).
#         NOTE: `langgraph` itself is NOT listed here, not because the
#         package is unused, but because these 5 tests happen not to touch
#         langgraph.graph / langgraph.types (StateGraph / Command /
#         interrupt / ToolNode), which the rest of the project DOES use
#         (app/agent/agent.py, app/api/chat.py,
#         app/services/tools/status_tool.py). It is only omitted from this
#         CI-only file; the real user install (requirements.txt) keeps it,
#         and requirements.txt is guarded separately by the full-install
#         job in .github/workflows/test.yml (pip install -r requirements.txt
#         + python -c "import main").
#         Re-add `langgraph~=1.2.9` here if a test ever imports
#         langgraph.graph / langgraph.types.
#   P0-2  import app.services.vector_store
#         -> embedding_factory (langchain_openai.OpenAIEmbeddings)
#         -> langchain_chroma.Chroma (pulls chromadb transitively)
#         -> app.config.settings (pydantic-settings)
#         Note: settings declares SILICON_API_KEY / EMBEDDING_API_KEY as
#         REQUIRED fields and vector_store instantiates them at import
#         time, so CI exports placeholder values (the smoke tests make
#         no network requests).
#   P0-3  import app.services.bm25_service -> jieba + rank-bm25 + numpy
#   P0-4  app.config.settings -> pydantic-settings (already listed above)
#   P0-5  stdlib only (codecs / pathlib)
#

# _clean_venv). Keep this file pure ASCII or UTF-8 BOM: pip on zh-CN Windows
