## 三、图件与脚本

- `figures/`：架构图、部署图、模块图、ER 图、一期 2 层 DFD
- `screenshots/`：真实运行截图（登录、工作台、知识库问答）
- `scripts/`：文档生成脚本（python-docx + PIL），可重新生成图件与文档
  - `fig_bd2.py` 概要设计三图；`fig_er.py` ER 图；`fig_dfd2b.py` 数据流图
  - `build_bd2.py` 概要设计说明书；`build_datamodel.py` 数据模型书；`build_testplan.py` 测试计划
  - `patch_srs_phase1.py` / `patch_phase2.py` 一期二期口径改造
  - `probe_toc_bd2.py` 目录页码探测（红标题法）

重新生成示例：

```bash
pip install python-docx pillow
python scripts/fig_bd2.py            # 先出图
python scripts/build_bd2.py          # 再出文档
```
