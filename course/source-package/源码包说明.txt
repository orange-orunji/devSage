一、包内目录说明
--------------------------------------------------------
app/                后端源码
  api/              接口层：chat（对话/SSE）、document（上传）、auth（认证）、kb（文档管理/指标）
  services/         业务层：检索（hyde/bm25/rerank）、文档解析、向量库、历史记录、工具集
  agent/            LangGraph 状态图编排（检索必经节点、工具循环、中断恢复）
  schemas/          ORM 模型与 Pydantic 模型
  utils/            数据库、鉴权、消息队列、任务处理、日志等基础设施
  config/           配置（.env 读取、Chroma/路径等）
  data/             运行期数据目录（上传、向量库、会话历史、日志；包内为空）
frontend/           前端源码（Vue 3 + Vite）
  src/              视图（登录/工作台/设置/文档管理）、组件、composables、样式
tests/              冒烟测试
docs/               项目自身文档（不含演示媒体）
scripts/            评测与维护脚本
main.py             应用入口（FastAPI）
worker.py 等        异步任务消费者入口（app/worker.py）
Dockerfile          三阶段构建（node 构建前端 → python 依赖 → 运行时）
docker-compose.yml  四容器编排（api / worker / redis / rabbitmq）
requirements.txt    Python 依赖
.env.example        环境变量模板（真实 .env 不入库）
README.md           项目说明、技术架构、快速开始、路线图

--------------------------------------------------------
二、运行前准备（详见《系统部署说明书》）
--------------------------------------------------------
1. 复制环境变量模板并填写：
      cp .env.example .env        # Windows: copy .env.example .env
   必填：SILICON_*（大模型）、EMBEDDING_*（向量化）
   可选：SMTP_*（邮件）、JWT_SECRET、REDIS_PASSWORD、RABBITMQ_*

2. Python 环境：
      python -m venv .venv
      .venv\Scripts\activate            # Windows
      pip install -r requirements.txt

3. 前端构建（后端会托管 dist）：
      cd frontend && npm install && npm run build

4. 启动：
      # 接口与页面
      .venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 9000
      # 文档解析 worker（另开窗口；队列不可用时上传会自动降级为同步处理）
      .venv\Scripts\python.exe -m app.worker

5. 访问：http://127.0.0.1:9000
   系统无内置账号，首次使用请点击“注册”创建。
   需要删除知识库文档时，执行：
      python -m app.make_admin <用户名>

--------------------------------------------------------
三、Docker 一键部署
--------------------------------------------------------
      docker compose build
      docker compose up -d
      # 访问 http://<服务器IP>:8001，管理台 http://<服务器IP>:15673

四、说明
--------------------------------------------------------
1. 本包不含 .env（含密钥）、app.db（含账号哈希）、向量库与上传文件等运行期数据，
   首次启动会自动创建数据库表与向量库目录。
2. 演示视频与 GIF（docs/show/，约 75 MB）未纳入本包，可在代码仓库中查看。
3. 课程交付文档（11 件）单独提交，不在源码包内。
4. 目录中未包含 node_modules、.venv、__pycache__ 等可再生文件。
